# Tableau Plan

## Dashboard 1 — Executive Overview

Purpose: surface manufacturing health and direct attention to anomalous periods/segments.

Planned elements:
- FPY, defect rate, DPPM, rework rate, scrap rate;
- week-over-week KPI deltas;
- FPY trend;
- factory/product comparison;
- actions into Manufacturing Quality.

## Dashboard 2 — Manufacturing Quality

Purpose: investigate performance by factory → product → line → component → defect.

Planned elements:
- weighted FPY trend;
- defect Pareto;
- yield-loss contribution;
- benchmark comparison;
- parameter-driven metric selection;
- dashboard filter/action drill-down.

## Dashboard 3 — Root Cause Analysis

Purpose: distinguish true process deterioration, supplier/component concentration, test-station issues, and product-mix effects.

Planned elements:
- selected-period vs baseline decomposition;
- contribution ranking;
- mix vs within-segment comparison;
- evidence panel suitable for AI explanation.

## Later — Supplier Analytics

Supplier delivery/OTIF analytics is deferred until the manufacturing-quality MVP is complete.
